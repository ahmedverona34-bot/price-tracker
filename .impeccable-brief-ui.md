# Surface brief: price-tracker main window (`ui/`)

Mode: Operate. Audience: non-technical Arabic-speaking shoppers on Windows.

## Direction contract

THESIS: One keyword in, cheapest real prices out. The window refuses dashboards that admire data; every pixel serves scan → compare → open-or-export. No metrics hero, no kickers, no decoration.

OWN-WORLD: Near-black solid ground, charcoal cards with 1px hairline borders and 16–20px radii, pill tags, one electric cobalt accent (active nav, primary button, focus), white/soft-gray text, green only on discount percents. Thmanyah Sans in 300/400/500/700/900 (never 600). Flat surfaces, 150ms transitions, no blur, no gradients, no glow except the primary button's soft blue shadow.

STORY: Visitor types one Arabic word and watches rows stream into the table per site: the fast store lands in seconds with a green dot, the slow one keeps an amber dot while it works, and coupon notes fill in afterwards without blocking the view. Every filter (النوع, site chips, price, discount, text, sort, columns) answers instantly and tells the truth in the row count. Proof: real rows from live stores, honest before/after prices, coupon chips naming the code, change arrows vs the previous run.

FIRST VIEWPORT: Top engine bar (product name + engine-status pill); compact tool toolbar (wide search bar + blue استخراج الأسعار button, النوع segmented pills, site chips with status dots + row counts + duration); stat cards row (totals, discounted, average, min, max, update time); slim summary strip (row-count pill, live badge, countdown, refresh toggle, export group); dense sortable data table hero (sticky header, zebra hairlines, tabular numerals, change arrows, new badges, coupon chips, selectable rows, pagination); toasts for plain-Arabic status.

FORM: Pinned by brief (no roll: user-pinned direction beats the roll). RTL table-tool shell; pywebview over local ui/, Python js_api bridge, background-thread scraping pushed via polling; horizontal table scroll + wrapping toolbar at small widths.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
